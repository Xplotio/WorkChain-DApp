# WorkChain

WorkChain es una DApp de contratación freelance con pagos retenidos en contratos inteligentes.

## Profesiones soportadas

- Programadores
- Arquitectos
- Diseñadores gráficos
- Abogados

## Tecnologías

- Angular 20
- ethers
- Hardhat 3
- Solidity
- MetaMask
- Firebase Authentication
- Firestore
- IPFS como propuesta para evidencias verificables

## Problema

En trabajos freelance existe desconfianza entre cliente y trabajador. El cliente no quiere pagar sin recibir avances y el trabajador no quiere entregar trabajo sin garantía de pago.

## Solución

El cliente deposita fondos en un smart contract. El contrato retiene el dinero y lo libera por hitos aprobados. La plataforma cobra una comisión separada de los fondos retenidos.
